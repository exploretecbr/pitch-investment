# Explore — Pitch para Investidores

Deck de apresentação e roteiro do apresentador para a captação de investimento da **Explore**, marketplace de experiências turísticas em Natal/RN.

## Conteúdo

- **[`index.html`](index.html)** — Deck de 12 slides em 3 partes (**Custos · Crescimento · Retorno**), com gráficos SVG inline. Apresentável em tela cheia e exportável em PDF (`Ctrl + P`).
- **[`roteiro-apresentador.html`](roteiro-apresentador.html)** — Roteiro de fala slide a slide, cronometrado para ~5 minutos.

## Publicação (GitHub Pages)

O site é publicado automaticamente a cada push na branch `main` pelo workflow em [`.github/workflows/deploy.yml`](.github/workflows/deploy.yml).

**URL:** https://exploretecbr.github.io/pitch-investment/

## Design

Paleta *sunset · sea · sand*, tipografia Sora + Plus Jakarta Sans + Space Mono. Formato de deck 1280×720.

> Todos os números do pitch são cenários de planejamento e não representam garantia de rentabilidade.
